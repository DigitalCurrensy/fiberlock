# Fiberlock

Is the line clean enough?

If 11 percent or more of the checks on the line fail, nothing is saved. If the key on that line is shorter than 128 bits, nothing is saved. A GPS-only clock is refused. A clock that is too wide is refused.

It takes the error rate, the key length, and the clock grade from Phasepin. Photonseal will not sign a path that was not wrapped here.

It does not measure the cabinet, and it does not sign the record.
